# 利用規約

最終更新日：2026年7月6日

## 第1条（目的）

本規約は、個人（以下「運営者」といいます。）が提供する Web アプリケーションサービス「嗜み（Tashinami）」（以下「本サービス」といいます。）の利用条件を定めるものです。本サービスは、飲んだお酒の記録を残し、振り返ることを目的とした個人向けサービスです。

## 第2条（定義）

本規約において使用する用語の定義は、以下の通りとします。

1. 「利用者」とは、本規約に同意の上、本サービスを利用する個人（20歳以上）をいいます。
2. 「アカウント情報」とは、利用者が登録するメールアドレスおよび認証に必要な情報をいいます。
3. 「記録データ」とは、利用者が本サービスに入力する、お酒の銘柄、カテゴリ、評価、メモ、日時、飲んだ場所（店名や位置情報）、写真（アップロードする場合）をいいます。
4. 「技術情報」とは、Cookie、セッション情報、アクセスログ等、利用に伴い生成される情報をいいます。
5. 「外部サービス」とは、本サービスの提供にあたり利用する Supabase、Cloudflare、地図プロバイダ（MapLibre、Mapbox、Google Maps 等）をいいます。

## 第3条（利用資格）

1. 本サービスの利用資格は、20歳以上の個人に限ります。
2. 利用者は、本規約に同意の上、アカウント登録を行うものとします。

## 第4条（アカウント登録・認証）

1. 利用者は、本サービスの利用にあたり、運営者が指定する方法によりアカウント登録を行う必要があります。
2. アカウント登録は、メールアドレスによる認証を行います。
3. 利用者は、自己の責任において、アカウント情報およびパスワードを厳重に管理するものとします。
4. 利用者は、アカウント情報を第三者に譲渡、貸与、名義変更等をしてはなりません。

## 第5条（提供サービス）

1. 本サービスは、ブラウザで利用できる Web アプリケーションとして提供されます。
2. 本サービスは、飲んだお酒の記録（銘柄、カテゴリ、評価、メモ、日時、飲んだ場所、写真等）を保存し、一覧表示、検索、地図上での可視化、お気に入り TOP10、年次サマリーとして振り返ることができる機能を提供します。
3. 本サービスは、お酒の量や回数を競わせるものではなく、一杯ずつと向き合い記憶を積み重ねることを目的とします。
4. 本サービスは、基本的には利用者のプライベートな記録サービスですが、特定の記録や年次サマリーをリンクによる限定共有できる機能を提供します。

## 第6条（料金）

本サービスの利用料金は無料とします。ただし、将来的に有料オプション等を導入する場合には、別途利用規約またはお知らせにて通知します。

## 第7条（取得・保存する情報）

1. 運営者は、本サービスの提供にあたり、以下の情報を取得・保存します。
   1. アカウント情報：メールアドレスおよび認証に必要な情報。
   2. 記録データ：利用者が入力するお酒の銘柄、カテゴリ、評価、メモ、日時、飲んだ場所（店名や位置情報）、写真（画像アップロードを行う場合）。
   3. 技術情報：Cookie、セッション情報、アクセスログ等。
2. 写真や位置情報を含む記録データは、外部サービスである Supabase に保存される場合があります。

## 第8条（情報の利用目的）

運営者は、取得・保存した情報を以下の目的で利用します。

1. 本サービスの提供、表示、および機能（記録の保存、一覧・マップ・TOP10・年次サマリーの生成等）の実現のため。
2. 認証およびログイン状態の維持のため。
3. お問い合わせ対応、不正利用の防止、および本サービスの改善のため。
4. その他、利用者が同意した目的のため。

## 第9条（外部サービス・第三者提供）

1. 運営者は、本サービスの提供にあたり、以下の外部サービスを利用します。
   1. Supabase：アカウント情報および記録データを保存します。これらのデータは国外のサーバーに保管される可能性があります。
   2. Cloudflare：本サービスのホスティングおよび配信基盤として利用します。
   3. 地図プロバイダ（MapLibre、Mapbox、Google Maps 等）：地図機能の提供に利用します。
2. 運営者は、利用者の個人情報を、利用者の同意なく第三者に提供しません。ただし、法令に基づく場合、または人の生命、身体、財産の保護のために必要がある場合を除きます。

## 第10条（共有機能）

1. 利用者は、自己の責任において、特定の記録や年次サマリーを、推測されにくい URL のリンクで限定的に共有することができます。
2. 共有されたリンクを知る第三者は、対象の記録を閲覧できることに留意してください。共有は利用者の任意操作によるものとします。

## 第11条（ユーザーの権利・データ削除）

1. 利用者は、自己の記録データをいつでも編集または削除することができます。
2. 利用者は、いつでも退会（アカウント削除）を行うことができます。退会に伴い、アカウント情報および記録データは物理的に削除されます。
3. 利用者は、自己の保有個人データについて、開示、訂正、利用停止等の請求を、本規約に定める運営者連絡先にて行うことができます。運営者は、当該請求を受けた場合、法令に基づき適切に対応します。

## 第12条（禁止事項）

利用者は、本サービスの利用にあたり、以下の行為をしてはなりません。

1. 法令、公序良俗、または本規約に違反する行為。
2. 他者の権利（知的財産権、プライバシー権等）を侵害する行為。
3. 不正アクセス行為、または本サービスの運営を妨害する行為。
4. 20歳未満の飲酒を助長または推奨する内容の投稿、またはそれに類する行為。
5. その他、運営者が不適切と判断する行為。
